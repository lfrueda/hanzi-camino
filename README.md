# 汉字 · Camino

App para aprender chino: vocabulario del libro, radicales, hanzi y frases.
Funciona sin internet y se puede instalar como app (Safari → Compartir → Agregar a pantalla de inicio).

Apartados: 今 Hoy (repaso espaciado) · 课 Libro (lecciones) · 写 Planas (orden de trazos) · 树 Árbol (radical → hanzi → palabras).
